Este dashboard funciona mediante machine learning y simulaciones estocásticas que procesan el historial de los torneos:

  1. Limpieza Estricta y Orden Cronológico: El sistema agrupa transmisiones simultáneas para evitar duplicados. Se aplica un filtro del Cuantil 98% para descartar picos virales extremos (outliers) que podrían desfasar al modelo. Todo el historial se procesa en orden temporal para hacer un train/test evitando la fuga de datos.
  2. Ingeniería de Variables: El modelo respeta las categorías de transmisión (AAA, AA, A, B) como base predictiva, pero añade una capa matemática detectando la presencia de equipos importantes en la cancha (sumando 0, 1 o 2). Esto le enseña al algoritmo a afinar la proyección y diferenciar un partido regular de un partido de alto perfil dentro de la misma categoría.
  3. Entrenamiento de Inteligencia Artificial (Random Forest): Un ensamble de 1,000 árboles de decisión aprende las relaciones no lineales entre impresiones, interacciones, jerarquía de los equipos y fases finales (Liguilla). El margen de error se calcula utilizando métricas Out-Of-Bag (OOB), es decir, el modelo se evalúa a sí mismo usando únicamente partidos que "no vio" durante su entrenamiento, garantizando un margen de error 100% realista.
  4. Control de Riesgo (Shrinkage a la Media): Si un equipo no tiene suficiente historial jugando como local en una categoría específica, el sistema no adivina ni usa picos atípicos. En su lugar, aplica una técnica quant llamada Shrinkage, promediando el rendimiento histórico del equipo con el rendimiento global de toda la Liga en esa categoría. Esto estabiliza las proyecciones para equipos con pocos datos.
  5. Simulación Monte Carlo (10,000 Iteraciones): El modelo no arroja un solo número estático. Utilizando la predicción base y el margen de error OOB, se simulan 10,000 escenarios posibles por cada partido usando una Distribución Normal Truncada (que impide matemáticamente que existan views negativos).
  6. Rango de Confianza y Campana Visual: De las simulaciones se extrae la predicción central y el Rango Central (P25 - P75), aislando el 50% de probabilidad más certera. La Campana de Gauss en la tabla dibuja este horizonte: el centro representa el cumplimiento exacto (100%) de la proyección, y la esfera de color muestra el posicionamiento porcentual del rendimiento real respecto a nuestra meta matemática.
